Manager Guide
Performance & Probationary Reviews

A step-by-step guide to setting up, completing, and saving reviews for your team — no technical experience needed.

Overview

What this tool does

The Oliver Review Tool helps you run two types of conversations with your team: a 90-day probationary check-in for new starters, and a structured annual performance review. Everything is stored in a single file that you control.

📋

Probationary Plan

Set clear goals for new starters from day one. Assess progress across six areas and record a formal outcome at the 90-day mark.

📊

Annual Review

Track objectives, four quarterly check-ins, Oliver core values, and a final rating — all in one place, for each year.

💾

Your data, your file

Data saves automatically while you work. You export a backup file to SharePoint so nothing is lost if you switch device or browser.

Getting Started

Opening the tool for the first time

The tool is a single HTML file. You open it in your web browser — no installation, no login, no app to download.

1

Find the file on SharePoint

Your HR team will share a link to the file on SharePoint. Click the link — the tool will open in your browser (Chrome, Edge, or Safari all work fine).

You can also download the file and save it to your desktop if you prefer to open it offline. Right-click the link and choose Save link as.

2

Add your first employee

Click the + New Employee button in the bar at the top of the page. Enter the person's name, job title, and start date, then click Create.

The tool will take you straight to their Employee Profile. You can switch between team members using the dropdown at the top at any time.

3

Fill in the Employee Profile first

The Profile tab is the starting point. Make sure the name, job title, manager name, POD/team, and start date are all filled in — these appear on printed reviews and exports.

Using the Tool

The three tabs explained

Each employee record has three tabs. Work through them in order — Profile first, then Probationary, then Performance Review.

👤
Profile

Employee Profile

Basic details that appear on all documents. Always start here and keep it up to date if roles or managers change.

  • Setting the Start Date here also pre-fills the probationary plan start date automatically.
📋
Probation

Probationary Goals (90-Day)

For new starters. Use this tab to set expectations from day one and record the formal review outcome around day 70–90.

  • Set the Probation Start Date — the tool calculates the day-90 target date for you.
  • Add goals and describe what success looks like for each one.
  • At the review, rate the employee across six areas and select an outcome: Pass, Extend, or Fail.
  • Always write a comment in the Manager Comments box to explain your reasoning.
📊
Review

Performance Review (Annual)

For the full-year review cycle. Each year is stored separately — you can go back and view previous years at any time.

  • Use the Review Year selector at the top to switch between years.
  • Click + New Year at the start of each new review year to create a fresh record without touching the previous year.
  • Complete the four meetings in order: Goal Setting → Q2 Check-in → Q3 Check-in → Final Review. Enter the date of each meeting when it happens — the card will turn teal to confirm it is done.
  • Add objectives early in the year. Give each one a clear description, a weight (all weights must add up to 100%), and a target date.
  • Rate the employee on each of the four Oliver Core Values with a short comment to back it up.
  • Complete the Final Review section at year end with an overall rating and comments from both you and the employee.
Saving Your Work

How saving works — and why you need a backup

The tool saves automatically every time you type — you will see a green "Saved" notice in the top bar. But this automatic save only works on the browser and device you are currently using. If you clear your browser history, switch to a different computer, or open the tool in a different browser, that automatic save will not be there. To protect your work, you need to save a backup file to OneDrive.

⚠️

The automatic save is not enough on its own

Think of the automatic save like a temporary notepad. Your OneDrive backup is your permanent record. Get into the habit of exporting after every review conversation — it takes less than a minute and means your data is always safe.

One-Time Setup — Do This First

Create your backup folder on OneDrive

You only need to do this once. It takes about two minutes and gives you a permanent, secure home for your review files that you can access from any device.

1

Open OneDrive

Go to office.com in your browser and sign in with your Oliver work email and password. Once you are in, click the grid icon (⊞) in the top left corner and select OneDrive from the list of apps.

You can also open OneDrive directly at onedrive.com and sign in with your work account.

2

Create a new folder

Once you are in OneDrive, click + New (top left of the page) and select Folder from the dropdown menu.

Name the folder something clear, for example: Team Reviews — then click Create. The folder will appear in your OneDrive file list.

3

Open the folder and keep this tab open

Click to open your new Team Reviews folder. You will see it is empty for now. Keep this browser tab open — you will come back to it each time you save a backup.

Tip: Bookmark this folder now so you can find it instantly next time. In your browser, press Ctrl + D (Windows) or Cmd + D (Mac) to save a bookmark.

Every Time You Finish a Session

Saving your backup — 3 steps, under 1 minute

Do this at the end of every session where you have added or changed anything in the tool.

1

Export your backup from the review tool

In the review tool, click the ⤓ Export JSON button at the top right of the page. Your browser will automatically download a file. It will have a name like:

review_Jane_Smith_2025-06-30.json

This file will appear in your Downloads folder — the same place files go when you download anything from the internet.

2

Upload the file to your OneDrive folder

Switch to your OneDrive browser tab (the Team Reviews folder you set up earlier). Click Upload at the top of the page, then select Files.

A window will open. Go to your Downloads folder, find the file you just exported (it will be at the top of the list as the most recent download), select it, and click Open.

If a file with the same name already exists, OneDrive will ask if you want to replace it — click Replace. OneDrive keeps a version history automatically, so the old version is never lost.

3

Done — your data is safely backed up

The file is now saved securely in the cloud. You can access it from any device by logging in to OneDrive with your work account.

✅

A faster way: drag and drop

If you have your OneDrive folder open in one browser tab and your Downloads folder visible, you can simply drag the exported file from Downloads directly into the OneDrive browser tab. This is quicker than clicking Upload every time.

Restoring Your Data

Getting your data back on a different device

If you switch computers, clear your browser, or open the tool in a different browser, follow these steps to restore everything.

1

Download your backup file from OneDrive

Go to office.com, sign in, and open OneDrive. Open your Team Reviews folder. Find your most recent backup file (it will have today's or the most recent date in the name). Click the three dots ( ··· ) next to the file and choose Download. The file will go to your Downloads folder.

2

Open the review tool and import the file

Open the review tool in your browser as normal. At the top right, click ⤒ Import JSON. A file picker window will open — go to your Downloads folder, select the file you just downloaded, and click Open.

3

All your data is restored

The tool will load all your employees, objectives, check-in notes, and review history exactly as you left them. You can carry on where you left off.

Sharing & Printing

Exporting and printing a review

You have three options for sharing a completed review.

🖶

Print to PDF or paper

Click the 🖶 Print button at the top right. This opens your browser's standard print window. To save as a PDF instead of printing on paper, change the printer to "Save as PDF" (or "Microsoft Print to PDF" on Windows). This is the cleanest format to share with HR or keep on file.

⊞

Export to Excel

Click the ⊞ Export Excel button. This downloads a spreadsheet with separate tabs for the profile, probationary plan, objectives, core values and meetings. Useful if HR needs the data in a format they can work with directly.

⤓

Export JSON (your full backup)

The ⤓ Export JSON button saves everything — all employees, all review years, all notes — into a single backup file. This is what you re-import to restore your work. It is not meant for sharing with HR; it is your personal working file.

Frequently Asked Questions

Common questions

I have more than one person in my team. Can I manage them all in one place?

Yes. Click + New Employee for each team member. Use the dropdown in the top bar to switch between people. When you export a JSON backup, it includes every employee in the tool — so one file backs up your whole team.

It is a new year. How do I start fresh without losing last year's review?

Go to the Performance Review tab and click + New Year. Enter the new year and click Add. A completely blank record is created for that year — the previous year is untouched and you can switch back to it any time using the year selector.

I accidentally closed the browser without exporting. Is my work lost?

Almost certainly not — as long as you are on the same browser and the same device, the tool will load your last saved state automatically when you reopen it. Open the tool again and check. If everything is there, export a backup immediately so you are protected going forward.

I switched computers and my data is not there. How do I get it back?

Go to office.com, sign in, open OneDrive, and find your Team Reviews folder. Download your most recent backup file (the one ending in .json). Then open the review tool, click ⤒ Import JSON, select that file, and click Open. All your data will be restored.

I cannot find my OneDrive or I do not know how to sign in.

Go to office.com in your browser and sign in with your Oliver work email (the one you use for Outlook). Once in, click the grid icon in the top left and select OneDrive. If you have trouble signing in, contact your IT support team — they can help you access your Microsoft 365 account.

Can another manager see my review data?

No — not unless you deliberately share the file with them. The data lives in your browser and in your personal OneDrive folder. Your OneDrive is private to you by default. Do not store the file in a shared team folder unless that is intentional.

Another manager wants to use this tool. Do they need a separate copy?

Yes — each manager should open the tool independently in their own browser and maintain their own OneDrive backup folder. Each manager's data is completely separate. Do not share a single JSON file between managers, as importing one person's file will overwrite the other's data.

I want to remove an employee who has left the team.

Before deleting, export a JSON backup so you have an archive copy if it is ever needed. Then select the employee from the dropdown, click the red Delete button, and confirm. The record is removed from the tool but preserved in any backup file you saved before deleting.

The tool is not working or something looks wrong.

First try refreshing the page (press F5 or Cmd + R). If that does not help, try opening the tool in a different browser (Chrome or Edge work best). If you still have an issue, contact your People team with a description of what you were doing when the problem occurred.
