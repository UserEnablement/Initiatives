Manager Guide — Performance Review

Read this before opening the Performance Review for the first time. It takes about 3 minutes.

Before You Begin

What this tool does

The Performance Review helps you run two types of conversations with your team.

📋

Probationary plans for new starters

Set clear goals from day one. Three structured check-ins at Goal Setting, Day 30, and Day 90 help you track progress and record a formal outcome.

📊

Annual performance reviews

Four meetings across the year — Goal Setting, Q2, Q3, and Final Review — with objectives, progress tracking, core values, and a final rating.

The tool saves automatically as you type. Once you link your Team Reviews folder on OneDrive — a one-time step covered on the next page — every change saves there too, automatically. Nothing to remember after that.

Getting Started

Four steps — done once, then it runs itself

The Performance Review runs in your browser via a link — no file to download, no installation, no login.

1

Open the Performance Review

When you receive the link to the Performance Review, open it in your browser. Bookmark it straight away so you can find it again easily: press Ctrl+D (Windows) or Cmd+D (Mac) and save it to your browser toolbar. The link will be provided at the end of this guide once you have confirmed you have read everything.

Chrome or Edge work best — they support automatic folder saving. If you use Firefox or Safari, the folder-linking feature is not available; use ⤓ Export Backup after each session instead and upload it to OneDrive manually.

2

Link your Team Reviews folder — do this first, once

You will see a yellow bar at the top of the tool saying "No folder linked." Click Link your Team Reviews folder. A window opens asking you to pick a folder.

If you do not have a Team Reviews folder yet: open office.com in a new tab, sign in with your work email, go to OneDrive, click + New → Folder, name it Team Reviews, then come back here and pick it. Once linked, the bar turns green and every change saves there automatically — one file per person, privately, with no extra steps from you.

3

Add your team members

Click + New Employee in the bar at the top. Enter their name, job title, and start date. Click Create. Repeat for each person. Use the dropdown to switch between them.

4

Fill in the Profile tab first

Always complete the 👤 Employee Profile tab before anything else — name, job title, manager, POD, and start date. This appears on all printed reviews and setting the start date pre-fills the probationary plan automatically.

Using the Tool

The three tabs — work left to right

Each employee has three tabs. Work through them in order.

👤

Employee Profile

Basic details used across everything. Always start here and keep it updated if roles or managers change.

📋

Probationary (90-Day)

Set the probation start date — the Day 90 target is calculated for you. Record the date of each meeting as it happens: Goal Setting → Day 30 → Day 90. The Outcome section (pass, extend, or fail) only unlocks once the Day 90 meeting date is entered.

Each goal has a progress tracker with three columns — one per meeting. During or straight after each check-in, select a status for every goal: 🔴 Not started, 🟡 In progress, or 🟢 On track, and add a short note on what you observed. Do this at the time — the pattern across the three meetings becomes your evidence when deciding the outcome at day 90.

When you record a Pass, the tool will prompt you to move to the Performance Review tab and set up objectives — do this as soon as possible. If you select Extend, the tool asks for a new review date and what specifically needs to change during the extension period. If you select Fail, contact the People team before taking any further steps.

📊

Performance Review

Record meeting dates as they happen: Goal Setting → Q2 → Q3 → Final Review. Add objectives at the start of the year and update progress at each check-in. Core Values and the Final Review section only appear once the Q3 date is recorded — keeping the form relevant to where you are in the year.

To start a new review year, click + New Year at the top of this tab. Previous years stay on record.

Keeping Your Data Safe

If you linked your folder, you are already covered

Once your Team Reviews folder is linked, the tool writes each person's file there automatically on every change — one file per person, privately. There is nothing else you need to do during a normal session.

✅

Folder linked — what this means in practice

The green bar at the top confirms you are connected. Every time you type, the current person's file updates in your Team Reviews folder on OneDrive. When you open the tool next time, it loads everything back automatically.

⚠️

If the bar is yellow — reconnect before you start

Browsers drop folder permissions when you close and reopen a tab. If you see a yellow bar, click Reconnect before making any changes. It takes one click and your data is protected again.

If You Are Not Linked

If you are using Firefox or Safari, or have not yet linked a folder, saving is manual. Use ⤓ Export Backup in the top bar after each session — it downloads a file for the current person. Store it in your Team Reviews folder on OneDrive. To restore on another device, use ⤒ Import JSON and select that file. One person at a time — they load without affecting anyone else.

Switching Devices

Open the tool on the new device → click Link your Team Reviews folder → pick the same OneDrive folder. The tool reads all your employee files from the folder and loads them in. Done.

When a Manager Leaves or Changes Teams

Employee review data is stored in your personal OneDrive folder and does not transfer automatically. If you are leaving or handing over a team, please do one of the following before your last day:

📁

Share your Team Reviews folder with the incoming manager

In OneDrive, right-click your Team Reviews folder → Share → enter the new manager's email. They can then download the relevant employee files and import them into the tool. Alternatively, email the individual JSON files directly to Agnes (agnes.m.lech@gmail.com) and she will ensure records are passed to the right person.
